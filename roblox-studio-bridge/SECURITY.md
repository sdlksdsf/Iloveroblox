# Security notes — read before you run anything

You are right to be careful: an agent that can edit your game can also break it. Here is what
this bridge is, what it can and cannot do, and how to check every claim yourself.

## The one-paragraph version

`bridge.py` is a single, readable Python script with **no third-party dependencies**. It starts
Roblox's *own* MCP server using the *exact* command Roblox publishes in its documentation, then
relays JSON between that server and a **private GitHub repo** you own. It installs nothing,
needs no administrator rights, opens no incoming ports, and never downloads or executes any
other file.

## Exactly what touches your PC

| Action | Detail |
|---|---|
| **Files written** | `bridge.config.json` (your token) and `bridge.log`, inside this folder |
| **Files read** | Its own config, Roblox's `mcp.bat`, and the Python standard library |
| **Programs run** | Exactly one: `cmd.exe /c cd /d %LOCALAPPDATA%\Roblox && .\mcp.bat` — Roblox's own launcher |
| **Network, outbound** | **One host only:** `api.github.com` (HTTPS) |
| **Network, inbound** | **None.** It never calls `bind()`. Your firewall stays closed. |
| **Registry / services / drivers** | Untouched |
| **Administrator rights** | Not required. Do **not** "Run as administrator" |

## The GitHub token — the one real secret

Create it at <https://github.com/settings/personal-access-tokens/new> with:

- **Repository access:** Only select repositories → `roblox-studio-bridge`
- **Permissions:** Contents = **Read and write** (nothing else)

That token can read and write **one empty private repo** and nothing else. It cannot see your
other repositories, your email, your account settings, or your code.

- It is generated by you, stored only in `bridge.config.json` (gitignored, never uploaded).
- It is pasted into the Arena chat **once** so both sides can reach the same repo.
- **Revoking:** GitHub → Settings → Developer settings → Personal access tokens → **Delete**.
  The bridge dies instantly and nothing else on your PC is affected.
- Prefer a **90-day expiry**. Renewing is one click.

If you ever suspect the token leaked, delete it and create a new one. Cost: two minutes.

## What it can do to your game

Whatever Roblox's MCP server can do — because that is the whole point:

- read and write scripts anywhere in the place
- run Luau in Edit, Client and Server contexts
- start/stop playtests, read the Output window
- save the place (**not** publish — players never see changes until you publish)
- insert assets, generate meshes/animations

So the real question is not "is the script safe" but "do I trust the agent I am talking to".
Treat the bridge like handing someone your Studio keyboard.

## Privacy

The relay repo carries your game's scripts, tool results and screenshots in plain text. That is
why it **must be private**. `SETUP.bat` refuses to continue on a public repo unless you
explicitly type `yes`. Delete the repo when you are done with the project.

## How to verify the file is what it claims to be

1. **Read it.** One file, ~600 lines. Search for `subprocess`, `urllib`, `open(`, `os.system`,
   `eval`, `exec`, `pickle`, `socket`, `ctypes`, `winreg`. Every hit is accounted for below.
2. **Check the hash** and compare it with the one the agent quotes:

   ```
   python -c "import hashlib;print(hashlib.sha256(open('bridge.py','rb').read()).hexdigest())"
   ```

3. **Watch it.** Windows Resource Monitor (`resmon`) → Network → filter `python.exe`. You will
   see one remote address: GitHub.
4. **Block it.** An outbound firewall rule blocking `python.exe` stops the bridge completely
   and affects nothing else.

## Every sensitive-looking line, explained

| Code | Why it exists |
|---|---|
| `subprocess.Popen(...)` | Starts Roblox's `mcp.bat`. The command is a fixed list, never built from user input. |
| `urllib.request.urlopen(...)` | The only network code. One host, HTTPS. |
| `open(...)` / `os.replace(...)` | Reads/writes `bridge.config.json`, `bridge.log`, `status.json`. |
| `base64.b64encode(...)` | Encoding JSON for the GitHub contents API. Not obfuscation — you can read every message in the repo. |
| `threading` | One thread reads Roblox's stdout, one reads stderr, one is the main loop. |
| `secrets.token_hex(...)` | Names for scratch files. Cryptographically secure. |
| `getpass.getpass(...)` | Reads your token without echoing it to the screen. |

There is no `eval`, no `exec`, no `pickle`, no `socket`, no `ctypes`, no `winreg`, no
`os.system`, no auto-update, no telemetry, no hidden download.

## Threat model — honest assessment

| Threat | Status |
|---|---|
| Random internet user drives your Studio | **Blocked.** They would need your private repo *and* a token with write access. |
| Someone reads your game code in transit | **Blocked.** HTTPS to GitHub. |
| Someone reads it in the repo | **Blocked** as long as the repo is private. |
| Malicious code hidden in the bridge | **Not possible without your help** — you can read every line. |
| A bad AI action damages your place | **Possible.** Save to file before big changes; keep version history on. |
| Bridge keeps running after you forget it | Close the window. It appears in Task Manager as `python.exe`. |
| Token leaks through chat history | Low risk, but real. Delete the token if the chat is shared. |

## Uninstall

1. Close the bridge window.
2. Delete this folder.
3. Delete the token at <https://github.com/settings/personal-access-tokens>.
4. Delete the `roblox-studio-bridge` repo if you no longer want the history.

There is no installer, so there is nothing to uninstall. Nothing is left behind outside the
folder, apart from Roblox's own MCP files which Studio manages.
